# 🧮 아인매스

슬라이더와 버튼으로 값을 직접 바꿔보면서 수학 개념을 눈으로 확인하는 교육용 웹사이트입니다.
초등학교 저학년부터 고등학생까지를 대상으로, 공식을 외우기 전에 "왜 그런지"를 먼저 체험할 수 있도록 만들고 있습니다.

🔗 **사이트 바로가기**: https://ainmath.com

## 구성

- **체험 페이지** — 슬라이더/버튼으로 값을 바꾸면 그래프나 도형이 실시간으로 반응하는 인터랙티브 페이지
- **설명 글 (article-\*.html)** — 각 체험 페이지와 짝을 이루는 읽을거리. 개념의 배경, 실생활 연결, 학습 팁 등을 담고 있습니다
- **소개 / 이용약관 / 개인정보 처리방침 / 문의하기** — 사이트 운영 관련 정보 페이지
