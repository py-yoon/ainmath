포물선은 어떻게 움직일까?

y = ax² + bx + c에서 세 상수를 슬라이더로 조절해보세요. a는 포물선이 벌어지는 정도와 방향을, b와 c는 포물선의 위치를 결정해요.

a (이차항 계수)1
b (일차항 계수)0
c (상수항)0
y = 1x² + 0x + 0
꼭짓점: (0, 0) · 축: x = 0
a의 부호가 포물선이 위로 볼록한지(a>0) 아래로 볼록한지(a<0)를 결정하고, |a|가 클수록 폭이 좁아져요. 꼭짓점의 x좌표는 항상 -b/(2a)로 구할 수 있어요.
