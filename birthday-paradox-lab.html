🎂 생일 역설 실험실

딱 23명만 모여도
생일이 겹칠 확률이 반이 넘는다?

1년은 365일이니까, 생일이 같은 두 사람을 만나려면 엄청 많은 사람이 모여야 할 것 같죠? 그런데 딱 23명만 모여도 그중 생일이 같은 두 사람이 있을 확률이 50%를 넘어요. 직관과 정반대라서 '역설'이라고 불려요.

착각하기 쉬운 이유는, 흔히 "나와 생일이 같은 사람"을 떠올리기 때문이에요. 그런데 우리가 구하는 건 "23명 중 어느 누구든 두 명이 겹칠 확률"이에요. 23명이면 가능한 짝의 수가 23×22/2 = 253쌍이나 돼요. 253번이나 "혹시 겹칠까?"를 확인하는 셈이니, 확률이 훌쩍 높아지는 거예요.

🎂 인원수를 늘리면 확률은?

사람 수를 슬라이더로 바꿔가며, 그중 생일이 겹치는 두 사람이 있을 확률을 확인해보세요.

인원수별 확률을 막대그래프로 비교해보면, 23명 근처에서 확률이 얼마나 가파르게 올라가는지 한눈에 보여요.

🎲 직접 생일을 뽑아보기

인원수를 고르고 버튼을 눌러 실제로 무작위 생일을 뽑아보세요. 여러 번 뽑으면서 실제로 얼마나 자주 겹치는지 확인해보세요.

🧩 생일 역설 퀴즈

정답 0 / 시도 0
생일 역설의 핵심은 "짝의 개수"예요. n명이 있으면 짝의 개수는 n(n−1)/2로, 사람 수보다 훨씬 빠르게 늘어나요. 그래서 사람 수가 조금만 늘어도 겹칠 기회(짝의 수)는 폭발적으로 많아져요.
